# MARKET DESK 공개 웹 출시

첫 배포는 로그인과 결제가 없는 **연습판**이다. 실제 자금·실시간 호가·공개 랭킹은 이 출시의 범위에 포함하지 않는다. 웹을 먼저 검증하고, Android는 별도의 [Play 출시 절차](play/RELEASE.md)를 따른다.

## 출시 판정

1. `npm ci`, `npm run build`, `npm test -- --runInBand`를 통과시킨다.
2. 빌드된 웹에서 데스크톱과 모바일 Chromium의 `e2e/desk.spec.ts`를 실행한다. 로그인 없이 첫 주문, 캠페인 진입, 새로고침 뒤 저장 유지, 도움말·개인정보 경로를 확인한다.
3. 배포할 커밋과 공개 URL을 함께 기록한다. 로그인하지 않은 다른 브라우저 및 휴대폰 네트워크에서 루트 URL을 열어 로그인이나 초대 화면 없이 첫 주문이 되는지 확인한다. `/privacy`, `/delete-account`, `/support`도 주소창에서 직접 열어 본다. 체크아웃 도메인이나 기존 쇼케이스 URL을 출시 링크로 대신 쓰지 않는다.
4. 배포 주소가 바뀌면 브라우저 로컬 저장도 분리된다. 기존 주소를 없애기 전에 계정 · 저장에서 파일 내보내기 → 새 주소에서 가져오기를 실제로 검증한다. 기존 주소의 공개 권한은 임의로 변경하지 않는다.
5. Android의 경우 위 확인과 별도로 실제 TWA 시작 주소의 `/.well-known/assetlinks.json`이 인증 없이 리디렉션 없는 HTTPS 200 JSON을 반환하고, 패키지 및 Play 앱 서명 SHA-256과 일치해야 한다. 빈 배열은 연결 성공이 아니다.

## 커뮤니티에 공유할 때

제목 예시: **[자작] 로그인 없이 해보는 주식·선물·옵션 모의투자 게임**

> 주식뿐 아니라 선물·옵션도 연습해 보고 싶어서 MARKET DESK를 만들었습니다. 실제 돈이나 실시간 시세는 안 쓰고, 로그인 없이 바로 가상 주문을 넣어볼 수 있습니다. 첫 거래에서 헷갈리는 부분이나 모바일에서 불편한 점 있으면 알려주세요.

공개 검증이 끝난 링크와 최신 모바일 화면을 붙인 뒤 각 갤러리 공지를 확인한다. 실제 게시와 계정 권한 변경은 출시 준비와 분리한다.
