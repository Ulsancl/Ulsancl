# 관찰 기록 기반 차트

차트는 시뮬레이션이 실제로 만든 가격의 관찰 기록을 사용합니다. 실제 증권 거래소의 체결 데이터가 아니며 거래량을 추정하지 않습니다. 모달에서 과거 가격을 난수로 역산하던 표현을 제거했습니다. 처음 실행하면 짧은 기록만 있고, 계산에 필요한 봉이 쌓일 때까지 해당 지표는 비어 있습니다.

## 원본 관찰과 봉의 경계

`observations`의 각 항목은 `{sequence, timeMs, gameDay, gameMinute, price}`입니다. `sequence`는 세션 내 0부터 증가하고 같은 가격의 관찰도 포함합니다. `gameMinute`는 자정부터의 분, 게임일은 1부터입니다. 데이터 보관은 상위 관찰 훅이 담당하며, 화면을 닫아도 기록하고 새 실행/시즌에서 초기화합니다. 차트는 저장 파일에 임의 과거를 추가하지 않습니다.

`aggregateObservations(observations, {kind, size, maxCandles})`는 원본을 수정하지 않고 유효한 관찰을 집계합니다. 관찰 횟수 봉의 경계는 `floor(sequence/size)`에 고정됩니다. 게임일 봉은 `floor((gameDay-1)/size)`를 사용합니다. 화면에 보이는 봉 수가 바뀌거나 새 관찰이 추가되어도 이미 완료된 봉의 OHLC를 다시 묶지 않습니다. 첫 관찰값이 시가, 마지막 관찰값이 종가이며 고가·저가는 실제 표본의 극값입니다. 소수 가격을 정수로 반올림하지 않습니다.

관찰 1·5·15·60회, 게임 1·3·5일을 선택할 수 있습니다. 분·주·월 이름에 임의의 관찰 개수를 대응시키지 않습니다. 현재 엔진의 게임 1일은 실제 300초이고 게임 시각은 09:00~16:00 범위를 10분 단위로 표시합니다. 따라서 서로 다른 관찰이 같은 게임 시각을 가질 수 있으며 상세의 관찰 횟수와 sequence가 이를 구별합니다.

각 봉의 ID는 `kind:size:bucket`이며 진행 중/완료, 일부 구간만 관찰했는지도 표시합니다. 보관 범위가 봉 중간부터 시작하거나 sequence가 빠지면 빈 가격을 채우지 않습니다. 게임일 최초 봉은 전체 거래일을 관찰했다고 보장할 수 없어 일부 관찰로 표시합니다.

## 가격·지표·선택의 동일한 시점

SMA·RSI·MACD·볼린저 밴드는 같은 관찰봉 종가에서 계산합니다. 각 결과는 원래 봉 인덱스에 정렬되며 준비 구간은 `null`로 남깁니다. RSI 14는 15번째 가격부터, MACD 12/26/9는 34번째 가격부터 나타납니다. 보조지표의 짧은 배열을 차트 전체 폭으로 늘리지 않습니다.

평탄 가격 RSI는 50, 상승만 있으면 100, 하락만 있으면 0입니다. 평탄 MACD도 유한한 0으로 표시하고, 폭이 0인 볼린저 밴드를 매수·매도 조건으로 표현하지 않습니다. 유효 값이 하나인 이동평균은 점으로 표시합니다. 준비 기간을 채우기 위한 합성 가격은 만들지 않습니다.

진행 중인 최신 봉도 계산에 포함하므로 그 봉의 가격과 지표는 변할 수 있습니다. 지표는 현재 보관된 관찰 범위를 기준으로 계산하며, 오래된 기록이 보관 한도로 제거되면 EMA의 초기값도 이 범위를 따릅니다. 계산 조건은 지표 설명이며 실제 투자 결과를 보장하지 않습니다.

가격축은 범위에 맞는 소수 정밀도를 유지하고 축약된 `5만` 같은 표시로 서로 다른 호가를 같게 보이게 하지 않습니다. 헤더는 당일 시가 대비 변화, 선택 패널은 선택한 관찰봉의 정확한 OHLC를 보여 줍니다. 현재가 0, 자산 0도 정상 값으로 보존합니다.

클릭·터치 또는 방향키로 봉을 선택하면 보이는 구간을 고정합니다. 새 관찰이 와도 선택한 봉의 ID는 유지됩니다. Home/End는 보관 범위의 처음/마지막을, 최신 따라가기는 새 관찰 추적을 선택합니다. Escape는 고정 선택을 해제하고, 선택이 없는 상태에서는 모달을 닫습니다. 보관 범위에서 선택 기록이 제거되면 이를 알립니다. 모달은 키보드 초점을 유지하고 종료 시 기존 초점으로 돌아갑니다.

## 자산 기록

자산 차트의 가로축은 실제 `timestamp` 간격이며 누락 시간 구간을 같은 간격으로 압축하지 않습니다. 마지막 기록 자산과 기록 시각을 함께 표시합니다. 약 10초 간격으로 기록하므로 현재 계좌 자산과 다음 기록 전까지 차이가 날 수 있습니다. 0원을 원금으로 대체하지 않으며, 초기 자산 대비 비율도 기록값으로 계산합니다.

## 검증

순수 데이터 검사는 고정 봉 경계, 불변 완료 OHLC, 소수 가격·동일 가격 관찰, 기록 부족/누락, 게임일 경계, 지표 준비 구간, 평탄 RSI/MACD, 정밀한 축과 불규칙 자산 시각을 다룹니다. 컴포넌트 검사는 가격봉과 보조지표의 실제 SVG X좌표, 새 데이터 이후 선택 유지, 유한한 평탄 차트, 단일 이동평균 점, 0원 자산 및 빈 관찰 화면을 확인합니다. 브라우저에서는 실제 관찰 훅과의 연결, 모달 재개방, 반응형 스크롤, 키보드·터치·주문 버튼의 단일 동작을 별도로 확인합니다.
